## MODIFIED Requirements
### Requirement: Draft Plan Includes Ten-Layer Landing Map

The draft production durable-team implementation plan SHALL include a visible landing map that explains the relationship between the earlier ten-layer capability framework and the current 12-layer lifecycle target. The plan SHALL state that the 10-layer model is a capability-core research canon and that the 12-layer model is the current platform/product lifecycle frame. The plan SHALL also state that this is draft documentation only, not runtime implementation evidence.

#### Scenario: Cold-start maintainer reads the draft plan

- **GIVEN** a maintainer opens `docs_bilingual/implementation_plans/codex_cli_personal_production_durable_team_plan.md`
- **WHEN** they look for the white paper or research layer model
- **THEN** the plan shows a dedicated 10-to-12-layer landing-map section before the lane-specific responsibility section
- **AND** the section states that this is draft documentation only, not runtime implementation evidence
- **AND** the section identifies the 12-layer lifecycle target as the current planning frame
