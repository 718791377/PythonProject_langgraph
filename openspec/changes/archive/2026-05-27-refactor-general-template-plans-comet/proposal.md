# Change: Refactor General Template Implementation Plans With Full Comet Governance

## Why
The General and General_2 Chinese implementation plans need a clean, decision-complete structure. The previous documents mixed historical notes, target-template facts, Comet clarification, and live-session context, which made cold-start execution risky.

## What Changes
- Refactor the `PythonProject_General` plan as the fuller governance template plan.
- Refactor the `PythonProject_General_2` plan as the local Git + OpenSpec + Superpowers + native subagents only plan.
- Add stable OpenSpec requirements for template implementation-plan governance.
- Record Comet/Superpowers design, implementation, verification, and archive evidence for this refactor.

## Impact
- No consumer project is mutated.
- No remote publication is performed.
- Future template work has clearer boundaries for Comet, OpenSpec, Superpowers, native subagents, oh-my-codex, native_omx, LangGraph, MCP scope, launcher payloads, and repo-local durable state.
