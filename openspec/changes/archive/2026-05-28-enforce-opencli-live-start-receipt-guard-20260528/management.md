# Comet Management Record

## Open / Initiating
- [x] Value and why are stated.
- [x] Success criteria are measurable.
- [x] Stakeholders, constraints, and operating boundaries are identified.

## Design / Planning
- [x] Delivery approach is tailored: full workflow, repo-local non-mutating guard slice.
- [x] Major risks and assumptions are recorded.
- [x] Acceptance evidence path is defined.

## Build / Executing
- [x] Execution mode is selected: `executing-plans` in an isolated worktree.
- [x] Quality evidence is recorded through tests and guard checks.
- [x] Blockers are cleared or have an explicit decision.

## Verify / Controlling
- [x] Variance from scope, design, and acceptance criteria is checked.
- [x] Risk and change impact are assessed.
- [x] Control decision `continue` means this local package may proceed to repository guard, local gate, local MR review, and local `main` integration.

## Archive / Closing
- [x] Value outcome is summarized.
- [x] Lessons learned or reusable guidance are recorded.
- [x] Delta spec sync, verification evidence, and archive path are confirmed.

## Monitoring Loop
- [x] Current facts are checked.
- [x] Continue, adjust, stop, or return decision is made.
- [x] No return is required.
