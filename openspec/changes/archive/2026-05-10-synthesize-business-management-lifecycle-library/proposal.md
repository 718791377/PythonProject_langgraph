# Change: Synthesize Business Management Library Into Product Lifecycle Docs

## Why

The local `Business Management/` reference library now contains the management, product, strategy, growth, architecture, and delivery books used to shape the personal Codex durable-team and one-person-company operating-system architecture notes. The product lifecycle docs should explicitly capture the resulting governance lessons so later sessions can apply the library without rereading every book from scratch.

## What Changes

- Add a source synthesis overlay to the product lifecycle documentation.
- Map the Business Management library themes to lifecycle layers, operating cadence, product discovery, delivery gates, architecture boundaries, growth, and learning loops.
- Preserve the boundary that repository docs summarize project-specific guidance and do not reproduce copyrighted source text.

## Impact

- Documentation-only change under `docs_bilingual/product_lifecycle/` and the product-lifecycle OpenSpec spec.
- No runtime behavior change.
