# Comet Management Record

## Open / Initiating
- [x] Value / Why is stated.
- [x] Success criteria are stated.
- [x] Stakeholders and constraints are identified.

## Design / Planning
- [x] Delivery approach tailoring is recorded.
- [x] Risks and key assumptions are recorded.
- [x] Acceptance evidence path is defined.

## Build / Executing
- [x] Execution mode is selected.
- [x] TDD / review / quality evidence is recorded.
- [x] Current blockers are cleared or have handling decisions.

## Verify / Controlling
- [x] Variance check is complete.
- [x] Risk/change impact is assessed.
- [x] Control decision is recorded.

## Archive / Closing
- [x] Value outcome is summarized.
- [x] Lessons learned are recorded.
- [x] Delta spec sync / verification evidence / archive path decision is confirmed.

## Monitoring Loop
- [x] Current phase facts are checked.
- [x] Return/no-return decision is made.
- [x] If return is needed, target_phase and rework_reason are recorded.
