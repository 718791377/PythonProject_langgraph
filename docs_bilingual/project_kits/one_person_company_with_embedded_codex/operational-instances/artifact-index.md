# Artifact Index

## Purpose

Indexes evidence, source documents, ledgers, runtime records, review outputs, and links. This file is a fillable record for one operational instance, not a third white paper and not a regenerated 48/60 operations package.

## Authority Boundary

This entrypoint keeps the operational instance boundary explicit: business truth stays with the one-person company, Codex execution truth stays with the embedded Codex platform, and mixed evidence is linked without merging truth ownership.

Canonical authority tokens: operational instance; business truth; Codex execution truth; evidence; fillable record.

## Inputs

- Instance name, product or customer cycle, and operating horizon.
- Linked white papers, North Star documents, lifecycle rules, and project-kit templates.
- Known business, Codex, and mixed evidence sources.

## Tools And Techniques

- Boundary classification: business, codex, or mixed.
- Traceability mapping across ledgers, runtime records, and review outputs.
- Human review when the instance affects commitments or release gates.

## Outputs

- A scoped operational instance record.
- A cadence and artifact map for daily, weekly, monthly, and quarterly use.
- Links to shared ledgers, Codex execution records, business records, and mixed dual-gate records.

## Fillable Record

| Field | Value |
| --- | --- |
| operational instance | project / product / customer cycle / release slice |
| scope | business / codex / mixed |
| evidence entrypoint | paths |
| cadence | daily / weekly / monthly / quarterly |
| linked_docs | paths |

## Review Notes

- Record only evidence that belongs to this instance.
- Link source documents instead of copying unrelated truth into this file.
- Escalate mixed items to the mixed-governance instance pack before commitments or remote-publication actions.
