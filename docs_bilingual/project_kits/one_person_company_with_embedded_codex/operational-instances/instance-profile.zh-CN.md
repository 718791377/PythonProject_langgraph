# 运行实例画像

## 目的

Defines the real operating boundary, owner, scope, assumptions, and non-goals for this instance. 本文件是一份可填写的运行实例记录，不是第三本白皮书，也不是重新生成 48/60 正文运营包。

## 权威边界

本入口用于明确运行实例边界：business truth 归一人公司，Codex execution truth 归内嵌 Codex 平台，mixed evidence 只做链接而不合并真相归属。

Canonical authority tokens: operational instance; business truth; Codex execution truth; evidence; fillable record.

## 输入

- 实例名称、产品或客户周期、运行时间边界。
- 关联的白皮书、北极星、生命周期规则和 project kit 模板。
- 已知的 business、codex、mixed 证据来源。

## 工具与技术

- 按 business / codex / mixed 分类边界。
- 把台账、runtime 记录和复盘输出建立可追踪映射。
- 当影响承诺或发布门时触发人审。

## 输出

- 已限定范围的 operational instance 记录。
- 可用于日、周、月、季运营的节奏和 artifact map。
- 指向共享台账、Codex 执行记录、业务记录和 mixed dual-gate 记录的链接。

## 可填写记录

| 字段 | 值 |
| --- | --- |
| operational instance | project / product / customer cycle / release slice |
| scope | business / codex / mixed |
| evidence entrypoint | 路径 |
| cadence | daily / weekly / monthly / quarterly |
| linked_docs | 路径 |

## 复盘备注

- 只记录属于本 operational instance 的 evidence。
- 通过 linked_docs 链接来源文件，不把无关真相复制进本文件。
- mixed 事项在承诺或 remote-publication 动作前必须升级到 mixed-governance instance pack。
