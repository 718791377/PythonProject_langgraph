# One-Person Company With Embedded Codex Project Kit

## Purpose

Orient the operator to the kit purpose, truth boundary, and usage model. This page belongs to the one-person-company with embedded Codex project kit.

## Kit Coverage

- startup checklist
- folder structure
- governance gates
- local-main workflow
- remote-publication gate
- monthly review
- business gate
- Codex execution gate
- mixed two-gate review
- rollback

## Truth Boundary

Business truth covers customers, revenue, pricing, contracts, support, legal posture, cashflow, and business learning. Codex execution truth covers agents, OpenSpec, worktrees, durable state, validation gates, release boundaries, local-main evidence, and runtime evidence. Shared ledgers connect records through scope, truth_owner, evidence_source, decision_right, and linked_docs.

## Inputs

- Current project scope, business facts, Codex execution evidence, and tailoring decision.
- Shared ledger fields: scope, truth_owner, evidence_source, decision_right, linked_docs.
- Local-main status, rollback evidence, and remote-publication gate status.

## Tools And Techniques

- Separate business truth from Codex execution truth.
- Apply business gate, Codex execution gate, or mixed two-gate review based on scope.
- Keep Agent work delegated-draft-only unless a human explicitly approves the final commitment.
- Record local-main evidence before claiming integrated execution work.

## Outputs

- A usable project-kit page for startup checklist, folder structure, governance gates, local-main workflow, remote-publication gate, or monthly review.
- Auditable evidence that business and platform governance remain connected but not confused.
