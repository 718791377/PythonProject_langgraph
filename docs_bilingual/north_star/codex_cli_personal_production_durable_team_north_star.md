# Codex CLI Personal Production Durable-Team North Star

This file is a discoverability alias for the content-authoritative North Star plan at `docs_bilingual/north_star_plan.md`.

## Authority

- Content-authoritative English file: `docs_bilingual/north_star_plan.md`
- Chinese companion: `docs_bilingual/north_star_plan.zh-CN.md`
- Durable-team corpus: white paper, governance research note, MRD, North Star plan, implementation plan, playbook, lifecycle maps, and OpenSpec specs

## Non-Goals
