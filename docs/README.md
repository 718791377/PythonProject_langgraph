# Repository `docs/` Directory

This directory is not the primary documentation library for this repository.

Use `docs_bilingual/` for durable repository documentation, including governance
policies, implementation plans, whitepapers, product lifecycle notes, startup
summaries, and registered English / Chinese document pairs.

`docs/superpowers/` is reserved for Superpowers runtime artifacts referenced by
the Comet workflow:

- `docs/superpowers/specs/` - Superpowers design documents.
- `docs/superpowers/plans/` - Superpowers implementation plans.

Keep generated or workflow-local Superpowers artifacts here only when the Comet
or Superpowers workflow explicitly records those paths. Do not duplicate
`docs_bilingual/` documents into `docs/`.
