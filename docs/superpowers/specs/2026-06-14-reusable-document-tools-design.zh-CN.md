# 设计：可复用文档工具提升

## 当前状态

投标文档工作区已有可工作的文档处理、Poppler 和向量检索辅助工具，但部分默认值绑定 `D:/project` 路径和项目专用来源权威假设。

## 目标状态

目标仓库提供三层可复用工具面：PDF 工具、文档流水线核心脚本、向量/检索框架辅助工具。消费者项目继续拥有真实数据、实际配置、输出根、权限、guard 规则和来源权威。

## 边界决策

- 消费者项目拥有真实配置、输出根、guard 规则、来源权威和数据。
- 便携 Poppler 作为本地忽略缓存，因为现有证据接入规则要求第三方二进制不进入 tracked source。
- 脚本在没有消费者配置时只使用调用方或当前工作目录下的本地输出默认值。
- 通用框架不得默认读取 `D:/project`、`D:/PythonProject_OpenClaw` 或其他消费者项目路径。
