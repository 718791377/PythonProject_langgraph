# Repository `docs/` Directory

`docs/` 不是本仓库的正式主文档库。

正式治理、实施方案、白皮书、产品生命周期、启动摘要，以及中英文成对登记的文档，应继续放在 `docs_bilingual/`。

`docs/superpowers/` 仅作为 Comet / Superpowers 工作流引用的运行时产物目录：

- `docs/superpowers/specs/` - Superpowers 设计文档。
- `docs/superpowers/plans/` - Superpowers 实施计划。

只有当 Comet 或 Superpowers workflow 明确记录这些路径时，才把对应运行时产物放在这里；不要把 `docs_bilingual/` 的正式文档复制到 `docs/`。
